# Figma Metadata

This directory contains machine-readable exports from the `P Sure UI v3-final` Figma frame. They support background and reference-asset generation; they are not the UI contract.

Use the images in [`../screens/`](../screens/) for visual review and the codebase tokens for implementation decisions. Refresh the exported metadata with `./scripts/figma/sync.sh` when the source design changes. The script requires a Figma token in `~/.figma_token`.
